# 个人工作台 · Personal Workbench

> 一个自托管个人中枢的演进档案与部署框架。完整产品把学习通、正方教务、微信账单、天气、聊天截图与共享相机等信息和操作收敛到同一个带访问口令的网页中，并配有一个能理解全站界面的 AI 助手。

**当前版本：V0.6（2026-10-17）** · Node 单端口 · 公开骨架零第三方依赖 · 电脑/手机双端适配

---

## 开源范围说明

本仓库是项目的**公开部分**，采用"框架与档案公开、业务实现私有"的方式维护：

| 内容 | 是否随本仓库发布 |
|---|---|
| 服务骨架（HTTP 入口、健康检查、静态托管、MIME 与路径校验） | ✅ 公开，见 `server.js` |
| 容器与部署配置（Dockerfile、docker-compose、systemd、nginx、安装脚本） | ✅ 公开，见 `deploy/` |
| 环境变量模板、启动脚本、示例课表种子、许可证 | ✅ 公开 |
| 完整版本演进档案（V0.1~V0.6 需求、决策、缺陷修复实录） | ✅ 公开，见 `docs/releases/` |
| 业务后端（学习通/教务/AI/天气/相机等模块、鉴权、WebSocket 推流） | 🔒 私有自用，不发布 |
| 业务前端（各功能页面、UI 地图、气泡助手、图标资源） | 🔒 私有自用，不发布 |
| 本机网关（校园网出网、天气上游抓取）与共享相机服务 | 🔒 独立私有项目 |

## 完整版系统架构（档案记录）

```
┌──────────────────────────── 浏览器（电脑 / 手机）────────────────────────────┐
│  总览 │ 学习通 │ 教务 │ 天气 │ 记账 │ 情报分析 │ 签到相机卡 │ 气泡 AI 助手   │
│              流场背景 / 昼夜皮肤 / 访问口令闸门                               │
└───────────────────────────────┬─────────────────────────────────────────────┘
                                │ HTTPS（同源 + 访问口令）
┌───────────────────────────────▼──────────── 云端自用服务器（Node）───────────┐
│  完整版入口：路由/口令鉴权/静态服务                                           │
│  学习通客户端（登录态、接口）│ 长效操作引擎（截图→分析→操作循环）             │
│  AI 双模型路由（轻量只读 / 旗舰执行）│ Chromium 池与 CDP 推流                 │
│  教务网关租约（主备选举、任务重投）│ 天气聚合与瓦片代理 │ 原子持久化          │
└───────┬───────────────────────────────────────────────────┬─────────────────┘
        │ 学习通/公网                                         │ 同源代理
        ▼                                                    ▼
   学习通服务器                                    独立共享相机服务（匿名可选）

┌──────────────────────── 本机网关（校园网/家宽，私有）─────────────────────────┐
│  教务：正方登录、验证码识别、课表/成绩/选课                                    │
│  天气：上游 JSON 与瓦片抓取，主机白名单 + 分级缓存                             │
│  通道：长轮询领任务 → 本机 IP 出网 → 结果回传；多实例主备租约                  │
└──────────────────────────────────────────────────────────────────────────────┘
```

**为什么完整版需要本机网关：** 教务系统对来源 IP 做白名单限制，云服务器可达但所有 TCP 端口被丢包，只有校园网/家宽可访问；天气上游密钥同理经本机出网，浏览器永远拿不到密钥。

## 技术选型（完整版的关键取舍）

| 维度 | 选型 | 取舍理由 |
|---|---|---|
| 运行时 | Node.js（业务代码仅用标准库） | 单文件易部署，供应链面最小 |
| 浏览器自动化 | 直连 Chromium CDP（容器内通过 Playwright 安装内核） | 无需重型自动化框架；并发锁/代次令牌/登录态探测自行管控 |
| AI 操作 | 双模型分级 | 简单问答走轻量模型只读高亮；复杂任务走旗舰模型真实执行 |
| 校内穿透 | Python 网关 + 长轮询 | 无需公网入站端口；纯标准库可打包；主备租约支持多实例 |
| 前端 | 原生 JS/CSS（无框架） | 静态文件按请求读盘，更新免构建 |
| 视觉 | Canvas 2D 流场背景 | 非 WebGL，低端机与减弱动效偏好可降级静止 |

## 快速开始（公开骨架）

环境要求：Node.js 18+。骨架零依赖，无需安装任何包。

```bash
node server.js
# 默认监听 0.0.0.0:3000，可用 PORT / HOST 环境变量覆盖
```

启动后：

- `GET /api/health` 返回服务状态与版本号；
- 根路径返回 `public/index.html` 骨架状态页。

容器方式同样可用：`docker build --build-arg WITH_BROWSER=0 -t workbench .`（骨架不需要浏览器内核层）。

完整版的部署（学习通账号、AI 密钥、访问口令、本机网关、Chromium 内核）以私有代码库中的 `.env` 与 `deploy/` 配置为准；本仓库的部署文件保留了完整版所需的主要配置位与注释，可作为自建同类系统的参考。

## 接口说明

公开骨架仅提供：

| 端点 | 说明 |
|---|---|
| `GET /api/health` | 健康检查，返回 ok/status/version/time |
| `GET /*` | public 目录静态资源（含目录穿越防护） |

完整版另有学习通、AI/Agent、实时画面、教务网关、天气、相机代理等约 80 个接口，演进档案中按版本记录了它们的设计与修复过程，但接口实现不在本仓库。

## 安全设计（完整版对策，档案记录）

| 风险 | 完整版对策 |
|---|---|
| 页面裸奔 | 全站访问口令闸门，HTTP 与 WebSocket 双重校验 |
| 模型输出注入 | AI 文本一律文本节点渲染，禁止拼 innerHTML |
| 上游密钥泄露 | 天气/教务密钥仅存本机网关；浏览器只调云端同源接口 |
| 存储损坏 | 原子写入，半截损坏文件不覆盖旧数据 |
| 浏览器资源失控 | 启动单飞锁、推流代次令牌、busy 保护、空闲回收 |
| 路径穿越 | 文件接口路径规范化与前缀校验（公开骨架的静态托管同样包含此项） |

本仓库不包含任何真实密钥：`.env` 不入库，`.env.example` 全部为占位符。
