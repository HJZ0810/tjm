## 一、版本定位

V0.2 完成了"能力"（数据能抓、作业能做、教务能通），V0.3 解决"可用性与观感"：

- 学习通页从无限长卷改为**标签分页**，信息按域收纳；
- 被埋掉的**实时画面/运行日志**回归并与学习通工作区合并；
- 确立**克制、低文字密度、强动效**的视觉语言（DeepSeek 风格流场背景），并逐页分配异母题背景；
- 修复共享相机"拍照最急时被弹去登录"的严重体验事故；
- 天气系统立项（MSN 天气视觉复刻），其完整建设在 V0.4 展开。

## 三、V0.3.1 · 共享相机取消登录强制

### 3.1 事故背景

共享相机（camera.luo-jin-ai.com）用于课堂签到等时效性极强的场景，服务端却对**拍照页、查看页及全部接口**强制统一账户登录——未登录直接返回登录页，用户在最赶时间的拍照瞬间被打断。

### 3.2 定位与改动

| 维度 | 事实 |
|---|---|
| 服务形态 | server2 `/opt/camera-share`，Node 服务 3002 端口，nginx HTTPS 反代 |
| 强制点 | `/shoot.html`、`/view.html`、`/app.html`、`/api/*`、`/img/*` 均服务端校验统一账户身份 |
| 改动文件 | 服务端 `index.js`（改动前完整备份） |

四项改动：

| # | 改动 | 说明 |
|---|---|---|
| 1 | 门禁改匿名放行 | 有效会话则识别身份；无会话/会话失效一律按匿名访客（`guest`）放行，不再返回登录页或 401 |
| 2 | 上传身份兜底 | 上传元数据的 userId 增加 guest 兜底，匿名上传不再报错 |
| 3 | 移除 SSE 身份复查 | 删除实时推送通道的 60 秒定时身份复查，匿名用户的照片实时推送不会被中途掐断 |
| 4 | 审计降级 | 审计日志写入失败不再影响主流程；匿名访问在审计中记为 guest |

### 3.3 验证与保留能力

- 无 Cookie 访问全部页面与接口均 200，拍照页返回真实页面；实测匿名拍照上传成功，历史列表、图片访问、SSE 实时推送均正常；
- **保留**自愿登录入口，已登录用户身份照常识别——开放的是匿名通道，不是拆除账户体系。

## 四、V0.3.2 · 分页化、实时画面回归与视觉重构

### 4.1 问题清单（改版前实测）

| 区域 | 问题 |
|---|---|
| 学习通页 | 单页无限拉长，所有模块纵向堆叠，阅读成本高 |
| 实时画面 | 旧版存在的远程实时画面模式在新版"消失"（实际被埋进设置菜单的独立页面） |
| 总览 | 数字卡 + 纯文字列表，层次扁平、观感像行政系统 |
| 全站 | 文字说明过多，缺少图标、动效与交互反馈；纯白背景，视觉单调 |
| AI 元素地图 | 改版后大量新控件未登记，AI 不知道也点不到 |

### 4.2 信息架构改造

| 改造项 | 方案 |
|---|---|
| 学习通分页 | 复用教务页已验证的标签页模式（`data-tab` + 面板容器 + 懒加载，切换时才拉取数据），长卷拆为课程/作业/待办/签到等分域标签 |
| 实时画面回归 | 实时画面与运行日志合并为同一面板内的两个分块，单条 WebSocket 连接复用，不再作为藏在菜单里的独立页 |
| 实时画面合并三坑 | ① 全局只能建一条 WS，不能带 `frames=0` 重复握手；② state/log/agent 三类消息禁止重复订阅；③ 保留 `lastAt` 增量语义不被合并破坏 |
| 总览精简 | 从"完整列表"改为"图标 + 跳转卡片"，只展示概要与待办计数，详情进入专门页面 |
| 文案瘦身 | 删除心跳、本机端身份、网关在线数等面向运维的技术文案，技术信息转入文档/设置区 |

### 4.3 视觉体系：DeepSeek 风格流场背景

第一版视觉交付被评价为"只抄了蓝白配色，没有抄排版节奏"，随后确立可量化的视觉规格并重做：

| 维度 | 规格/决策 |
|---|---|
| 背景技术 | Canvas 2D + requestAnimationFrame 点阵流场（非 WebGL），鼠标跟随；点阵 spacing≈90，基色 rgb(60,100,160) |
| 视觉语言 | 克制的留白、分层透明度、入场动效与微交互，替代大段说明文字 |
| 逐页母题 | 各页面背景"同语言、异母题"，互不相同但不突兀；禁用 `mix-blend-mode`，单层不透明度 ≤ 0.10 |
| 天气页处理 | 采用"宿主接管"：天气页停掉全站网格绘制、压掉全局天空渐变，自带 100vh 背景，避免两层天空打架 |
| 性能红线 | `prefers-reduced-motion` 或帧率低于阈值时背景静止，不遮挡正文、不拦截点击 |
| 页面驱动 | 视图切换时写入 `body[data-view]`，由其驱动逐页背景变量；同时修正路由对两段式 hash（如 `#weather/hourly`）不匹配的问题 |

### 4.4 天气系统立项（本版立项，建设跨 V0.4）

- 目标：对标 MSN 天气做视觉与功能双复刻，定位城市石家庄；
- 取证：MSN 天气页为 SSR 直出，内联约 71KB 专属 CSS，可直接提取精确规格——主视觉 620×310、圆角 6px、温度字号 64px、详情网格、玻璃态（半透明 + `blur(60px)`）、18 组天气渐变、Segoe UI 字体族；
- 真实数据体检：聚合接口可提供小时级 219 条 × 18 项指标（温度/体感/湿度/风速/气压/UV/能见度/露点/云量/降水概率），支撑逐小时曲线与指标切换；
- 已识别阻塞：雷达地图依赖地图 Key 与瓦片通道，本版先落地不依赖底图的时间轴等部分，真底图方案在 V0.4 经天气网关解决。

### 4.5 AI 元素地图补全

页面大改后 AI 的可操作元素清单严重过期。本版对照真实 DOM 补登 14 个新控件并修正过期注释，建立"选择器清单 vs 页面真实元素"的自动对照测试，最终 **153 个选择器全部命中**，AI 对新版每个按钮/标签可知可达。

### 4.6 缺陷修复实录

| 现象 | 根因 | 修复 |
|---|---|---|
| 实时画面面板数据重复/抖动 | 合并后 state、log、agent 三类消息被重复订阅 | 单一 WS + 分通道单订阅，`lastAt` 增量语义保持 |
| 切到 `#weather/hourly` 等子页不生效 | 路由按整串匹配，两段式 hash 不命中 | 支持 `页面/子页` 两段路由 |
| 逐页背景不随页面变化 | 视图切换未写 `body[data-view]`，CSS 变量无驱动源 | 切换时落属性，背景按母题切换 |
| AI 找不到新页面的控件 | 元素地图停留在旧版 DOM | 补登 14 项 + 选择器对照测试防回归 |
| 首版天气地图空白 | 地图 Key 为占位符，空容器占位 | 识别为阻塞项，转入 V0.4 网关瓦片方案，不用假图填充 |

## 六、版本边界

- 天气系统本版仅完成立项、视觉规格取证与数据体检，主页/地图/月度/趋势等完整能力在 V0.4 交付；
- 流场背景以"克制"为硬约束，不追求动态复杂度，低端机与系统减弱动效偏好下默认静止；
- 相机开放匿名通道仅适用于该独立站点的定位（课堂签到时效性优先），工作台主站的访问口令保持不变。
