## 一、版本定位

V0.2 是项目的**第一次质变**：静态课表网页 → 部署在自有服务器上的一体化学习工作台。本版解决三个核心命题：

1. 把学习通网页 Agent 从开发机搬进自有云服务器，解除托管平台的能力限制，并让手机端可用；
2. 让 AI 具备"长效操作"能力——简单任务一步模拟，复杂任务实时截图、分析、操作，循环直到任务真正完成；
3. 攻克校方网络封锁，把只允许校园网访问的正方教务系统（课表/成绩/选课）通过本地网关接入云端。

## 三、V0.2.1 · 学习通 Agent 上云

### 3.1 起点问题

开发机上已有一个学习通网页 Agent 原型，但实测暴露四类问题：

| 问题类别 | 具体现象 |
|---|---|
| 数据不一致 | 页面部分区域无数据或数据对不上（如待办只在一处显示） |
| 鼠标能力残缺 | 只有"设置待办"类操作可用；页面跳转、滚动等动作链不完整；跨模块操作（转跳生活记账并创建一笔支出）只跳转不落地，直接点击报错 |
| 平台能力受限 | 运行在托管平台环境中，后端操作与长任务受平台约束 |
| 手机不可用 | 未做移动端适配 |

### 3.2 关键决策与落地

| 决策 | 方案 |
|---|---|
| 部署到自有服务器 | 服务端支持环境变量配置（`PORT`、`CX_SYNC_INTERVAL_MIN` 等），新增后台定时同步，进程脱离父 Shell 独立驻留 |
| 手机端可用 | 全站移动端适配，窄屏横向溢出专项治理 |
| 长效操作分级 | 简单任务直接派发模拟动作；复杂任务（做作业、看视频、答题）进入"截图 → 视觉分析 → 决策下一步 → 真实操作 → 确认结果"的 Agent 循环，直至任务完成并确认提交 |
| 不伪造状态 | 学习通作业直连 URL 因缺 `enc` 参数返回"无权限的操作"，证明直连接口路线不通——**作业状态必须由 Agent 走真实界面读取** |

### 3.3 真实作业扫描（夜间自主作业）

按"先摸清待办范围、再逐门完成"的策略，对账号下 **17 门课程**执行真实扫描，拿到基于界面读取（非接口推导）的待办清单，例如：线性代数 A 三次作业未交、电路与电子学实验 0/30、足球 0/86 任务点、大学物理第 1~6 章全空等。

扫描同时暴露一个引擎缺陷：**任务总结幻觉**——批量盘点的最终总结将所有课程写成"无"，与逐步日志中的真实读数矛盾。修复方式为新增 `report` 动作，要求盘点类任务**边查边落盘**，不再依赖模型最后一次性总结，真实数据以逐步动作为准。

### 3.4 缺陷修复实录（V0.2.1）

| 现象 | 根因 | 修复 |
|---|---|---|
| 手机端页面横向溢出（scrollWidth 564px） | 页面 URL 展示元素是 inline 子元素，`max-width: 52vw` 对 `display:inline` 完全不生效，规则形同虚设；长 URL 直接撑宽容器 | 将 URL 元素改为可收缩 flex item，整行允许压缩，320px 窄屏验证 |
| 虚拟按键条疑似溢出（假阳性） | 诊断误报——按键容器在 ≤900px 时本就是 `overflow-x:auto` 的横向滚动容器，不构成溢出 | 排除误报，不做无效改动 |
| 跨模块记账动作只跳转不落地 | 动作链缺少"跳转后等待 + 定位 + 点击/填写"的后续环节 | 补全动作链，真实落库验证 |

## 五、V0.2.3 · 教务网关落地与通宵加固（核心版本）

### 5.1 网络封锁的决定性发现

集成开工前的网络侦察得到一条决定架构的硬事实：

| 来源 | ping 教务主机 | TCP 80/443/8080/8090/8443 | 访问其他公网站点 |
|---|---|---|---|
| server2（云服务器） | 通（约 60ms） | **全部丢包** | 正常 |
| server1（云服务器） | 通 | **全部丢包** | 正常 |
| 校园网/家宽环境 | 通 | 8090 正常（约 158ms） | 正常 |

结论：校方按来源 IP 放行，**屏蔽 IDC 机房网段**。云端直连教务在网络层即不可行，由此确立"**本地出网网关 + 长轮询隧道 + 云端渲染**"的三段式架构。

### 5.2 教务网关（jw-gateway）

| 维度 | 设计 |
|---|---|
| 运行位置 | 用户本机（校园网/家宽环境），桌面快捷方式启动，开机可常驻 |
| 技术栈 | 纯 Python 标准库（urllib + http.server），可 PyInstaller 打包成免安装 exe |
| 验证码识别 | 双路：本地 ddddocr 与视觉大模型读图，结果交叉校验；未安装 ddddocr 时自动退化为纯视觉模式（标记 `vision-only`） |
| 通信隧道 | 网关持续向云端 `poll` 领任务 → 本机用真实校园网 IP 执行 → `result` 回传；`heartbeat` 5 秒保活。无需公网入站端口 |
| 接入功能 | 登录/登出、验证码、课表快照、成绩（含 GPA 计算）、选课（`enter/query/submit/exit` 完整一轮）、手动数据导入 |
| 启动脚本 | GBK 编码 + CRLF 行尾重写，含 Python 路径探测、依赖校验、崩溃自动重启、单实例保护；控制台输出按 GBK 适配（`PYTHONIOENCODING=gbk:replace`） |

**启动脚本编码事故**：初版 `.bat` 为 UTF-8 + LF，cmd.exe 在 `chcp 65001` 生效前已按系统代码页 GBK 解析文件，中文被拆成乱码碎片当作命令执行。重写为 GBK + CRLF 后恢复正常。

### 5.3 网关多实例主备租约（可分发能力）

需求目标：程序分发给任意同学，只要有一人开着，云端教务功能就可用；多人同时在线也不互相干扰。针对单网关设计的三个硬伤完成改造：

| 单网关隐患 | 主备租约方案 |
|---|---|
| 任务取走不还，网关宕机后任务只能等超时 | 租约机制：任务带租约心跳，持有者失联数秒内自动重投给其他网关 |
| 单个长轮询 waiter，新连接踢掉旧连接 | 多 waiter 注册，TCP 断开即时感知，接管可达秒级 |
| 同账号多点登录互相挤掉会话 | 同一时刻只有**主网关**真正登录教务、领任务、推快照，其余为备机待命 |
| 主网关所在网络连不通教务时占着主位 | 增加"教务可达性优先"选主：主网关若处于无法访问教务的网络，备机自动抢占主位 |

网关租约逻辑配套单测 66/66 通过，并完成双网关注册、强杀主网关、备机接管的真实端到端演练。

### 5.4 AI 双模型路由与反幻觉

| 机制 | 说明 |
|---|---|
| FAST / SMART 分级 | 简单问答走轻量模型，动作仅 `goto + highlight`（只读高亮，不跳转）；复杂操作走旗舰模型，产出 `do(...)` 交后台引擎真实执行 |
| JSON 截断自愈 | 轻量模型偶发返回半截 JSON 导致用户看到乱码时，自动升级旗舰模型重跑 |
| 删除"教模型撒谎"的提示词 | 旧提示词要求模型在数据未就绪时声称"正在同步，请稍后再问"，会让用户无限等待——整段移除 |
| 数字口径修正 | "26 门课"误报修正：26 是排课**条数**而非课程门数，去重后展示真实门数 |
| 空手承诺守卫 | 模型口头承诺"已经在做"但未产出任何动作时拦截并强制派发后台任务 |

**守卫漏网与修复**：多轮对话中前端会在每轮后注入一条合成的"系统反馈"消息，守卫从末尾找最后一条 user 消息时误捞到该合成消息，因其中无祈使词而放行了空手承诺。修复为：判定逻辑抽成可测纯函数并跳过合成消息，确定性单测 19/19 钉死该场景。

### 5.5 数据正确性专项（课表 / 进度 / 成绩）

针对"课表时间和渲染块不对、学习进度全 0 且课程重复、教务数据全空"等界面实测问题逐项查实：

| 现象 | 查实的根因 | 处理 |
|---|---|---|
| 教务面板全空 | 教务快照内容是登录页原文（"请先登录系统"），前端却按"无数据"渲染 | 区分"未登录/无数据"状态并正确提示与自愈（一次真实读取即可清除假性失效态） |
| 课表时间错位 | 课程节次按小节渲染，实际作息是**一大节顶两小节**（上午两大节、下午两大节、晚间视情况排课） | 按大节作息重排课表网格 |
| 学习进度全 0 且课程重复 | 26 条排课记录被当作课程堆入 courses，10 门课重复成 14 组；进度未按教学周次占比计算 | 课程去重分组，进度按当前周次/总周次计算 |
| 成绩读不到 | 读取位置与实际成绩页不对应 | 按真实成绩页路径重新对接，成绩/GPA 正确渲染（实测 GPA 3.21） |

### 5.6 通宵资源与安全审计（54 项修复中的高危项）

夜间以"自己当用户、全流程实测 + 三路并行子智能体审计"的方式，对长效操作链路完成系统性加固。高危项摘录：

| 问题 | 不可逆后果 | 修复 |
|---|---|---|
| 浏览器启动无并发锁 | 并发深读各起一个 Chromium，前一个变 150~300MB 孤儿进程 | 加单飞锁，复用同一浏览器实例 |
| Cookie 指纹只算 key 不算 value | 重新登录后深读永久落在登录页且无法自愈 | 指纹纳入 value，变化即重建会话 |
| 长任务中途掉线无探测 | 模型在登录页上认真操作，整段步数白烧 | 增加登录态探测，掉线立即中止并上报 |
| 重置/关闭不看 busy | 正在运行的长任务被腰斩成 Target closed | busy 期间拒绝 reset/close |
| 持久化层无损坏保护 | 断电产生的半截 JSON 会覆盖好数据，课表/记账/待办一次性清零却返回 ok | 原子写 + 损坏文件不覆盖 + 内存兜底 |
| 日志页共用推流通道 | 只看日志也持续截图推流，hold 导致会话永不回收 | 通道按用途隔离 |
| 模型输出直拼 innerHTML | 提示词注入可在页面执行脚本、窃取访问口令、接管学习通账号 | 全文本渲染，杜绝 HTML 注入 |
| 推流启停竞态 | 最后观看者在 startCast 异步窗口内断开时 stopCast 提前返回，推流常驻、浏览器无法回收（clients=0 仍 casting=true） | 推流引入代次（generation）令牌，废弃代次的启动结果一律回滚 |
| 日志同毫秒丢行 | 以 `Date.now()` 当唯一 ID，同毫秒两条日志后一条被增量拉取静默丢弃 | 单调序列 ID |
| 视频观看停止假响应 | 等待循环不检查停止标志，点"中断"后最多还要跑一小时 | 循环每步检查停止标志，立即真停 |

## 七、版本边界与遗留

- 教务功能依赖至少一台位于校园网/家宽环境的网关在线；无网关时云端教务面板展示未连接状态而非伪造数据；
- 学习通部分深层接口（如作业详情直连）受 `enc` 参数保护，统一走浏览器真实界面而非直连接口；
- 审计中识别但未在本版处理的设计级事项（业务数组容量上限、页面操作全局互斥锁、网关未解锁时请求挂起策略）已记录留待后续版本。
