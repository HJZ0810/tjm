# V0.5 · 双系统融合：共享相机进入学习通签到页

| 项 | 内容 |
|---|---|
| 版本号 | V0.5（V0.5.1） |
| 发布日期 | 2026-10-16 |
| 版本性质 | 跨站点能力融合（camera-share ↔ study-workbench） |
| 小版本数 | 1 次主线会话，含三次方向性纠偏与打磨 |
| 涉及服务 | 工作台后端（3210）、共享相机服务（3002） |

> 本文记录私有完整版的建设过程，文中点名的业务文件与接口均属私有代码库；本公开仓库仅含服务骨架、部署配置与演进档案。

## 一、版本定位

工作台已聚合学习、教务、记账、天气、情报分析五条线，但课堂签到仍需在两个站点间来回切换：在学习通看签到活动 → 跳到共享相机拍照/取图 → 再回到学习通提交。V0.5 把共享相机作为**原生卡片**嵌进学习通签到页，实现"看签到、拍照、选片、提交"在同一页面闭环。

## 二、需求边界（经三轮澄清钉死）

| 边界 | 结论 |
|---|---|
| 嵌入位置 | 学习通**签到页内新增一张可变卡片**，原有签到记录卡片及其全部 UI/设定**一字不动** |
| 嵌入形态 | **原生卡片**（工作台风格），禁止 iframe 套壳 |
| 卡片内容 | 两个选项（拍照 / 查看）+ 渠道输入框（与相机原 UI 一致）；默认渠道 HJZ，进入即展示该渠道第一张照片 |
| 交互方式 | 点击选项**在本页放大卡片**完成拍照/查看，不跳转到相机站点；按手机/电脑分别做尺寸适配 |
| 业务闭环 | 支持选择查看页中的照片提交到指定签到活动；支持扫描签到二维码完成签到 |
| 文案 | 不写文字提示，保持极简 |

## 三、技术方案

### 3.1 同源代理层

| 问题 | 方案 |
|---|---|
| 相机服务无 CORS，浏览器无法跨站直连 | 工作台后端新增 `/api/camera/*` 同源转发层（latest / upload / img / stream / delete） |
| 访问口令透传 | 全站 `gate.js` 已对 fetch 做统一包装并自动附带 `X-App-Token`，同源相机请求自然获得口令保护 |
| SSE 无法自定义请求头 | `EventSource` 不能附带自定义头，实时照片流改用 fetch 读取流式响应，复用口令包装 |

### 3.2 签到能力对接

| 能力 | 说明 |
|---|---|
| 签到活动读取 | `cx-client` 拉取当前签到活动，含类型（二维码 / 位置 / 手势 / 签到码 / 普通）与状态（open / signed / expired） |
| 拍照签到 | 选定照片后调用照片签到提交接口 |
| 二维码签到 | 前端引入纯前端 QR 解析库（jsQR），用户选择二维码图片后本地解码，再走签到码提交流程 |

### 3.3 相机服务端新增能力

融合需要"删除照片"能力，而原相机服务没有任何删除接口：

- 新增删除接口，含**路径校验**（防目录穿越）与 latest 回退（删除的恰为最新照片时，自动回指上一张）。

## 四、方向性纠偏记录

第一版实现偏离需求（做成"本地摄像头/手机拍摄"模式切换 + 随机渠道），经用户指出后整体返工至第二节定义的边界。该偏差在当轮即识别纠正，未污染签到记录卡片。

## 五、打磨项（第二轮反馈）

| 反馈 | 落地 |
|---|---|
| 拍过的照片不删除会一直堆积 | 手机**长按**、电脑**右键**唤出照片操作菜单（含删除），调相机侧新删除接口 |
| 照片需要能拖动 | 支持拖拽排序，并可拖到大图位查看 |
| 需要本地上传 | 卡片标题图标处设置**隐形上传入口**（无特效、无文字，点按即可选本地图片上传） |
| 默认渠道 | 固定默认 HJZ，进入卡片直接展示第一张照片 |
| 界面瑕疵 | 大图两侧留白修正、增加状态点、精简所有冗长提示文案 |

## 六、部署与验证

- 部署前对线上文件整包备份，上传 7 个变更文件并逐一做 md5 指纹核对；
- 前端静态文件按请求读盘即时生效，后端代理改动经服务重启生效；
- 验证链路：签到活动读取（含类型标签）→ 卡片加载与默认渠道照片 → 拍照/本地上传 → 照片流实时到达 → 选片提交签到 → 二维码解码签到 → 长按/右键删除与 latest 回退。

## 七、V0.4 → V0.5 总览对比

| 维度 | V0.4 | V0.5 |
|---|---|---|
| 签到流程 | 学习通与相机两站跳转 | 签到页一屏闭环 |
| 相机接入方式 | 独立站点 | 工作台原生卡片（同源代理） |
| 照片管理 | 仅拍摄/查看/上传 | 新增删除、拖拽排序、本地上传、latest 回退 |
| 实时流 | SSE（EventSource） | fetch 流式读取，口令统一 |
| 二维码签到 | 需另寻工具扫码 | 卡片内选图本地解码提交 |
| 对既有功能影响 | — | 签到记录卡片零改动，相机原站继续独立可用 |

## 八、版本边界

- 融合是**单向嵌入**：工作台消费相机能力，相机站点保持独立运行与匿名访问策略（见 V0.3.1）；
- 位置/手势类签到依赖学习通客户端环境与定位能力，本版闭环覆盖拍照签到与二维码签到两类；
- 照片删除为物理删除（带路径校验），删除前由用户在操作菜单中显式确认。
